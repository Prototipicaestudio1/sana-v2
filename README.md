## ✨ Funcionalidades
- 🎓 **Alumnos:** Chat IA, diario emocional, ejercicios de respiración
- 👨‍🏫 **Docentes:** Bitácora compartida, material didáctico
- 📚 **Regularización:** Material por materia
- 🔑 **Admin:** Gestión de escuelas
- 🔒 **100% Offline:** Sin dependencias externas
